## 起動
Node.js を用意し、`npm install` のあと `npm run dev` を実行してください。

## 初期版
- 3種類から2つの勉強法を選択し、事前予想を記録
- 別々の単語セットで5分学習タイマー
- 1問ずつ答えを見る自己採点テスト
- 正答率、グラフ、結果コメント
- localStorage による結果保存と履歴
- スマートフォン対応

翌日テストは次の開発項目です。単語は難易度をそろえたデモ用セットです。
