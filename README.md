# まなびラボ — 勉強法実験アプリ

自分に合う勉強法を、英単語の暗記実験で見つけるWebアプリです。

- 公開URL：<https://hakkasoxn.vercel.app/>
- 技術：React、TypeScript、Vite、Tailwind CSS、React Router、Recharts
- 保存先：ブラウザー内のlocalStorage（アカウント登録・端末間同期なし）

## はじめて使う

1. 公開URLを開き、「実験を始める」を選びます。
2. 比較する勉強法を2つ選び、結果を予想します。
3. 表示された単語を使って、それぞれ5分間学習します。
4. 各学習のあと、10問の自己採点テストに回答します。
5. 結果とグラフを確認します。過去の記録はヘッダーの「実験履歴」から見られます。
6. 翌日以降、履歴の詳細から同じ単語で翌日テストを受けられます。

結果は自己採点に基づく記録です。1回の実験で勉強法の効果を証明するものではありません。

## 開発環境

Node.js 24を使用します。

```bash
npm install
npm run dev
```

開発サーバーに表示されるURL（通常は `http://localhost:5173/`）をブラウザーで開きます。本番用ビルドは次のコマンドで作成します。

```bash
npm run build
npm run preview
```

## 実装済みの機能

- 3種類から2つの勉強法を選び、実験前の予想を記録
- 各勉強法の説明と、難易度をそろえた10語の問題セット（5セット）
- 一時停止・再開に対応した5分タイマー
- 日本語訳を表示・非表示にできる学習画面
- 1問ずつ進む自己採点テストと正答率の比較グラフ
- 予想と結果に応じたコメント、実験履歴と詳細
- 翌日以降の再テストと、直後・翌日の結果比較
- 実験途中の状態を保存し、再読み込み後に再開
- バージョン付きlocalStorage保存と旧形式の履歴移行
- PC・スマートフォン向けレイアウト

詳細は[発表・デモガイド](docs/発表・デモガイド.md)を参照してください。

## 公開・デプロイ

Vercelのビルド設定は `vercel.json` にあります。GitHubの `main` ブランチをVercelに接続している場合、mainへの反映後に自動デプロイされます。公開後は上記URLでホーム画面を開き、実験設定・直接URLアクセス・スマートフォン表示を確認してください。
