# 発表・デモガイド

## 発表の要点

**まなびラボ**は、勉強法を一方的におすすめするのではなく、同じ時間・異なる単語セットで2つの方法を試し、本人の予想と結果を比べるアプリです。結果は自己採点による今回の記録で、1回の実験で効果を断定しない設計です。

## 3〜4分のデモシナリオ

1. **ホーム（約20秒）** — 「実験を始める」を押し、アプリの目的を紹介します。
2. **実験設定（約40秒）** — 3つの勉強法から2つを選び、どちらが良さそうか予想します。選択が2つ揃うまでは進めないことも確認します。
3. **学習画面（約40秒）** — 方法の説明と単語一覧を紹介します。「思い出して覚える」では日本語訳の表示・非表示を切り替えます。タイマーは5分設定であることを示します。
4. **確認テスト（約30秒）** — 1問ずつ答えを確認し、「覚えていた／いなかった」で自己採点する流れを紹介します。デモ時間を短縮する場合は、ここで画面の操作を説明してから回答を進めます。
5. **結果（約40秒）** — 2つの正答率、比較グラフ、事前の予想との差、今回の実験に関するコメントを見せます。
6. **履歴・翌日テスト（約30秒）** — 結果が履歴に残ることを示し、詳細画面で翌日以降に同じ問題を使って再テストし、直後との比較を表示できることを紹介します。翌日テストは実験翌日以降に有効になります。

## デモ前の準備

- 公開ページを開き、ホーム画面が表示されることを確認する。
- 発表用ブラウザーの履歴を整理する。既存の履歴を使う場合は、個人情報や見せたくない記録がないことを確認する。
- 翌日テストのデモには、実験日が前日以前の履歴を用意する。用意できない場合は、利用条件と画面を説明し、翌日テスト部分は実操作を省略する。
- 5分タイマーを実際に待つ時間がない場合は、タイマーの設定を紹介し、残り時間が減るところまで見せて先へ進む。
- 表示結果はデモ用の自己採点記録であり、勉強法の優劣を実証するデータではないと伝える。

## 最終確認チェックリスト

### PC・スマートフォン

- [ ] ホームから実験設定へ移動できる。
- [ ] 勉強法を2つ選ぶと予想を選べ、必要な選択前には次へ進めない。
- [ ] 学習画面に10語と方法の説明が表示される。
- [ ] 思い出す方法で日本語訳を切り替えられる。
- [ ] タイマーを開始・一時停止・再開でき、再読み込み後に実験を再開できる。
- [ ] 自己採点テストが1問ずつ進み、10問の結果が正しく集計される。
- [ ] 結果・比較グラフ・予想・コメントを確認できる。
- [ ] 履歴と履歴詳細を開ける。
- [ ] 翌日以降の記録で翌日テストを完了し、直後との比較を確認できる。
- [ ] スマートフォンでも文字やボタンが読みやすく、横スクロールなしで操作できる。
- [ ] `/history` や実験結果のURLを直接開いてもアプリが表示される。
